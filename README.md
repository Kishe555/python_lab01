# Лабораторная работа №1 — консольный набор утилит

Программа содержит калькулятор арифметических выражений и конвертер
длины, массы и температуры. Управление выполняется через командную строку.

## Требования

- Python 3.10 или новее.
- pytest — для запуска тестов.
- pytest-cov — для измерения покрытия.
- Ruff — для проверки кода.


## Использование

### Справка

```powershell
python -m toolkit --help
```

### Калькулятор

Выражение передаётся одним аргументом в кавычках:

```powershell
python -m toolkit calc "2+3*4"
```

Результат: `14.0`.

Другие примеры:

```powershell
python -m toolkit calc "10 / 4"
python -m toolkit calc "2 * -3"
python -m toolkit calc "1.5+2.25"
```

Ожидаемые результаты: `2.5`, `-6.0`, `3.75`.

Для выражения, начинающегося с минуса, используйте разделитель `--`:

```powershell
python -m toolkit calc -- "-2+3"
```

### Конвертер

Формат команды:

```text
python -m toolkit convert VALUE --from UNIT --to UNIT
```

Примеры:

```powershell
python -m toolkit convert 1000 --from mm --to m
python -m toolkit convert 1.5 --from kg --to g
python -m toolkit convert 0 --from c --to f
```

Ожидаемые результаты: `1.0`, `1500.0`, `32.0`.

Отрицательное значение можно передать после разделителя `--`:

```powershell
python -m toolkit convert --from c --to k -- -273.15
```

Ожидаемый результат: `0.0`.

## Принцип работы калькулятора

Вычисление разделено на этапы:

1. `tokenization()` разбивает строку на числа и операторы.
2. `unar()` объединяет унарный знак со следующим числом.
3. `validation()` проверяет структуру выражения.
4. `RPN()` преобразует выражение в обратную польскую запись.
5. `solve_RPN()` вычисляет результат с помощью стека.
6. `solve()` последовательно вызывает эти функции.

Поддерживаются операции `+`, `-`, `*`, `/`.
Умножение и деление имеют приоритет над сложением и вычитанием.
Операции одного приоритета выполняются слева направо.

Для дробных чисел используется точка. Вычисления выполняются через
`float`, поэтому возможна небольшая погрешность.

Разбор `2*-3`:

```text
Токены:                 ["2", "*", "-", "3"]
После обработки знака:  ["2", "*", "-3"]
Обратная польская запись: ["2", "-3", "*"]
Результат:              -6.0
```

Вычислительное ядро не использует `input()`, `print()`, `eval()`,
`exec()` и сторонние библиотеки разбора выражений.

Дополнительное задание: реализованы преобразование в обратную польскую
запись и вычисление стеком.

## Принцип работы конвертера

Поддерживаемые единицы:

| Величина | Единицы | Базовая единица |
|----------|---------|----------------|
| Длина | mm, cm, m, km | Метр |
| Масса | g, kg | Килограмм |
| Температура | c, f, k | Кельвин |

Регистр единиц не учитывается: `MM` и `mm` обозначают одну единицу.

Длина и масса переводятся через коэффициенты:

```text
результат = значение × коэффициент исходной единицы
                     ÷ коэффициент конечной единицы
```

Температура сначала переводится в Кельвины, затем в конечную шкалу.
Значения ниже абсолютного нуля запрещены:

- Цельсий: ниже -273.15 °C;
- Фаренгейт: ниже -459.67 °F;
- Кельвин: ниже 0 K.

Перевод между разными группами величин запрещён.
Результат конвертации возвращается как `float`.

## Ошибки

Пользовательские исключения определены в `errors.py`
и наследуются от `ToolkitError`.

| Исключение | Назначение |
|------------|------------|
| Empty_Expression_Error | Отдельный класс для пустого выражения; пока не используется |
| Invalid_Expression_Error | Неверная структура или пустое выражение |
| Invalid_Symbol_Error | Недопустимый символ |
| Division_By_Zero_Error | Деление на ноль |
| Unknown_Unit_Error | Неизвестная единица |
| Incompatible_Units_Error | Единицы разных групп |
| Invalid_Temperature_Error | Температура ниже абсолютного нуля |

Неверное числовое значение конвертера вызывает `ToolkitError`.

CLI перехватывает `ToolkitError` и его наследников, выводит сообщение
в `stderr` и завершает программу с кодом `2`.
Успешная команда выводит результат в `stdout` и завершается с кодом `0`.

Код завершения последней команды:

```powershell
$LASTEXITCODE
```

## Проверки

Запуск тестов:

```powershell
python -m pytest -v
```

Проверка покрытия с номерами непроверенных строк:

```powershell
python -m pytest --cov=src/toolkit --cov-report=term-missing
```

HTML-отчёт покрытия:

```powershell
python -m pytest --cov=src/toolkit --cov-report=html
```

Отчёт сохраняется в `htmlcov/index.html`.

Проверка стиля:

```powershell
ruff check .
```

Тесты ядра вызывают функции напрямую, без запуска отдельного процесса.


- объяснить разбор выражения `2*-3`;
- объяснить приоритет операций и работу стека;
- добавить новую единицу длины;
- добавить тест несовместимых единиц.

Например, для поддержки дециметра в словарь `length` добавляется:

```python
"dm": 0.1,
```

Пример проверки:

```python
def test_decimeters():
    assert convert(10, "dm", "m") == pytest.approx(1.0)
```
